## 3. API 계약 (전부 `apiFetch` 경유, envelope 자동 unwrap)

| Method | Path | Request | 비고 |
|---|---|---|---|
| GET | `/api/v1/profiles/me` | — | 내 프로필 |
| POST | `/api/v1/profiles` | nickname, communityId, gender, ageRange | **null/빈문자열 키 제거** (신규) |
| PATCH | `/api/v1/profiles` | 위 4개 + residence/hometown province·district | **null→빈문자열** 전송(수정) |
| PATCH | `/api/v1/profiles/image` | profileImage(engName 대문자) | 색상 문자열 |
| GET | `/api/v1/profiles/nickname/check?query=` | — | 200=가능/409=중복/그외=형식오류 |
| GET | `/api/v1/communities` | — | 목록 |
| GET | `/api/v1/communities/search?query=` | — | 검색 |
| GET | `/api/v1/terms` | — | 약관 목록(온보딩) |
| GET | `/api/v1/terms/agree` | — | 내 동의현황 |
| POST | `/api/v1/terms/agree` | agreements:[{termsId, agreed}] | 동의 제출 |
| POST | `/api/v1/users/withdraw` | — | 회원 탈퇴 |

닉네임 체크는 `apiFetch`가 non-2xx에서 `[code] message` throw → `checkNickname`이 감싸 `available`/`duplicate`/`invalid`로 해석.

## 4. ✅ 지역 필드 포맷 = code (백엔드 확인 완료 2026-07-09)

- 웹은 지역 필드를 **숫자 code**로 전송/수신 — `residence/hometownProvince`="11"(서울), `residence/hometownDistrict`="11010"(종로구).
- **백엔드 코드 확인 결과 이 방향이 정답**:
  - `ProvinceType`/`DistrictType` enum의 `@JsonCreator`가 **code 기준으로 역직렬화** (`from("11")` → SEOUL). 이게 Jackson 기본 enum명 매칭을 덮어써서, 반대로 **enum명(SEOUL/JONGNO)을 보내면 `NOT_SUPPORTED_PROVINCE`/`NOT_SUPPORTED_DISTRICT` 에러**.
  - 응답(`ProfileResponse`)도 `.getCode()`로 **code 반환**.
  - Swagger `@Schema(example="11")`도 실제로는 code. (Swagger UI가 필드 타입을 enum 드롭다운으로 렌더해 SEOUL/JONGNO가 보였던 게 혼동 원인이었음. 실제 바디는 code.)
  - DB 저장만 내부적으로 enum명(SEOUL) — API 경계와 무관.
- 즉 **웹/모바일/백엔드 모두 code 로 정합**. 별도 조치 불필요.
- 참고: 지역 필드는 **수정(PATCH) 요청에만** 존재. 생성(POST)에는 없고 서버가 기본값 `UNDEFINED`로 저장.

## 5. 온보딩 플로우

소셜 로그인 성공 → `setTokens/setProfileStatus/setTermsStatus` → `nextAfterLogin`:
1. `termsStatus === false` → `/onboarding/terms` (약관 전체 동의 → POST) →
2. `profileStatus === false` → `/onboarding/profile` (프로필 생성 POST) →
3. `/profile/image?onboarding=1` (색상 선택 PATCH) → `/` (홈)

기존 유저(둘 다 true)는 바로 `/`.

## 6. 주요 로직 (모바일 미러)

- **닉네임**: 길이 2~8 + 정규식 `^[가-힣a-zA-Z]{1,8}$`. 통과 시 500ms debounce 후 중복확인. 기존 닉네임과 동일하면 확인 스킵. 입력값이 "검증 통과값"과 일치할 때만 저장 버튼 활성.
- **커뮤니티**: onInit 전체 목록 로드, 검색은 500ms debounce. 모달에서 임시 선택 후 "등록하기"로 확정.
- **성별/연령**: 3카드 / 모달 그리드.
- **거주지·출신지**(수정 모드만): 도→시군구 2단 모달. "거주지와 동일" 체크박스로 출신지 복사/해제.
- **이미지**: 신규는 랜덤 색상(effect), 수정은 현재 색상(`?color=`). 색상 engName PATCH.
- **탈퇴**: 정적 안내 + 확인 다이얼로그 → POST → 로컬 세션 클리어 → 홈.
