# 프로필/설정 v0.5.1 — GNB 드롭다운 + 설정 모달 + 반응형

> **작업일**: 2026-07-17 ~ 18
> **범위**: v0.5 프로필을 GNB 드롭다운 + 설정(모달) 구조로 재편. 프로필은 별도 페이지, 설정(계정/정책/문의)은 인터셉트 모달. 사이드바 반응형·프로필 read-only 필드 등 부수 개선.

---

## 1. GNB 드롭다운 (`RedditLayout.tsx`)
- 프로필 아이콘 클릭 → 드롭다운(바깥클릭/ESC 닫힘): **프로필 / 설정 / 로그아웃**. 온보딩(minimal)은 **로그아웃**만.
- 프로필 → `/profile`(별도 페이지). 설정 → `/settings/account`(모달). 로그아웃 → 확인 다이얼로그 후 홈.
- `LoginModal`을 `src/components/auth/LoginModal.tsx`로 추출(재사용).

## 2. 설정 모달 (`/settings/*`)
- 좌측(데스크톱)/상단 가로(모바일 반응형) 메뉴 — 순서 **계정 → 정책 → 문의**.
  - 계정(`/settings/account`): **소셜 로그인**(`GET /profiles/me`의 `socialType`, Kakao/Apple 표기) + 로그아웃 + **계정 삭제**(`/settings/account/delete`, 문구 "삭제 신청하기" + 돌아가기).
  - 정책(`/settings/policy`): **약관 동의**(동의내역) + **서비스 정책**(링크) 한 화면.
  - 문의(`/settings/support`): 카카오 채널.
- 인터셉트 모달(`@modal/(.)settings/*`) + 직접진입 폴백 페이지. 내부 이동은 `replace`(닫기 X 한 번에 완전 닫힘).
- `@modal/[...catchAll]` 제거 — 비인터셉트 페이지(`/profile` 등) 소프트 내비게이션이 새로고침 없이 갱신되도록(catch-all이 형제 슬롯 갱신을 막던 이슈).

## 3. 프로필 페이지 (`/profile`)
- 모달 → **별도 페이지**로 전환. 아바타·닉네임·프로필수정·소속 커뮤니티.
- **내 정보(read-only)** 섹션 추가: 성별/연령대/거주지/출신지. 값 없으면 "미설정". 지역은 `regionLabel(code)`로 표시명 변환.
- 수정 페이지: **수정 취소** 버튼(변경 폐기 후 `/profile`).

## 4. 부수 개선
- **사이드바 반응형**(`RedditLayout`): 좁아질 때 **왼쪽 먼저**(<lg) → 오른쪽(<md). 하단 네비 `lg:hidden`로 공백 방지. 우측 사이드바 구분선·배경 제거(본문과 합침).
- 모달 스크롤락 시 **페이지 흔들림 제거**(`html { scrollbar-gutter: stable }`), `DeModalSheet` backdrop 블러 + `size`/`bodyClassName` prop.
- 소셜 로그인 노출을 스토어→**API(`profiles/me.socialType`)** 로 전환.

## 5. 삭제된 파일
`@modal/(.)profile/*`, `@modal/[...catchAll]`, `profile/{terms,withdraw}` 페이지, `Profile{Dialog,ModalShell,TermsContent,WithdrawContent}`, `home/LiveDebateCard` 등.
