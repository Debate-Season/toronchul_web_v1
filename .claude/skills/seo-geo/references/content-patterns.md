# GEO 콘텐츠 패턴

> **언제 읽나** — 페이지 본문 문구를 쓰거나 검토할 때.
> 근거는 `geo-evidence.md` §1 (Princeton GEO 논문). **페이지 종류마다 최적 기법이 다르다.**

---

## 적용 매핑

| 페이지 | 1순위 기법 | 이유 |
|---|---|---|
| **토론 상세** | **Authoritative + Statistics** | 논문의 Debate 도메인에서 **Authoritative 가 유일하게 유의미**. Opinion/Debate 에서 Statistics 도 최적 |
| **이슈위키** | **Cite Sources** | Statement/Facts 도메인의 최적 기법 |
| **이슈 맥락 설명** | **Quotation Addition** | People & Society, Explanation, History |
| **AI 뉴스** | **Cite Sources + Statistics** | 원본 조사 부재 신호를 상쇄한다 → `ai-news.md` |
| 전 페이지 | **Fluency** | 정보 추가 없이 가독성만 올려도 +15~30% |

**Keyword Stuffing 은 하지 않는다.** 개선이 없을 뿐 아니라 Perplexity 에서는 베이스라인보다 10% 나빴다.

## 정의형 문단 — 페이지 첫 문단

LLM 이 가장 잘 인용하는 형태다. **문맥 없이 그 문장만 떼어내도 의미가 통해야 한다.**

```
{이슈명}은 {명확한 정의}. {발생 시기}에 시작됐으며 {핵심 쟁점}이 논점이다.
{날짜} 기준 토론철에서 {N}개 주제로 {M}명이 토론 중이며, 찬성 {X}% · 반대 {Y}%.
```

## 통계 블록 — 상단 배치

구체 수치와 날짜를 페이지 위쪽에. 사실 밀도가 인용 확률을 올린다.

```
- 토론 주제: 2개
- 총 발언: 428건
- 찬반: 찬성 25 · 반대 10
- 참여 커뮤니티: 디시인사이드 40% · 에펨코리아 25% · 기타 35%
- 최종 갱신: 2026-08-20
```

**이 수치는 토론철만 가진 원본 데이터다.** 다른 데서 복제할 수 없는 자산이고, GEO 상 가장 강한 카드다.

## 진행 경과 요약 — 토론 페이지

```
찬성 측은 {요지}를 근거로 든다. 반대 측은 {요지}를 든다.
{날짜} 이후 {변화}가 관찰된다.
```
